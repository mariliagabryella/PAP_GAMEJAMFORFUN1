<p><strong>🎮 Game Jam For Fun – Website</strong></p>

<p><strong>📌 Descrição do Projeto</strong></p>
<p>
O Game Jam For Fun é um website desenvolvido no âmbito do curso Técnico de Gestão e Programação de Sistemas Informáticos (TGPSI), com o objetivo de divulgar e gerir inscrições para um evento real – uma Game Jam destinada a alunos do 9.º ao 12.º ano.<br><br>
O site permite não só apresentar informações sobre o evento, como também gerir conteúdos de forma dinâmica através de um painel de administração.
</p>

<p><strong>🎯 Objetivos</strong></p>
<p>
Criar um site funcional e intuitivo<br>
Permitir inscrições online para o evento<br>
Centralizar toda a informação da Game Jam<br>
Desenvolver um sistema de gestão de conteúdos dinâmico<br>
Aplicar conhecimentos de desenvolvimento web
</p>

<p><strong>🛠️ Tecnologias Utilizadas</strong></p>
<p><strong>Front-End</strong><br>
HTML<br>
CSS<br>
JavaScript</p>

<p><strong>Back-End</strong><br>
PHP<br>
MySQL</p>

<p><strong>Ferramentas e Bibliotecas</strong><br>
CKEditor 5 (editor de texto avançado)<br>
SortableJS (drag & drop de imagens)<br>
XAMPP (servidor local)<br>
FileZilla (transferência de ficheiros para servidor)<br>
GitHub (controlo de versões)
</p>

<p><strong>⚙️ Funcionalidades Principais</strong></p>

<p><strong>🔐 Sistema de Autenticação</strong><br>
Login de administradores<br>
Gestão de sessões
</p>

<p><strong>📝 Painel de Administração</strong><br><br>
Permite editar todo o conteúdo do site sem necessidade de programar:<br><br>
Títulos e textos<br>
Informações do evento<br>
Patrocinadores<br>
Contactos
</p>

<p><strong>🧠 Editor de Conteúdo (CKEditor)</strong><br>
Edição visual tipo Word<br>
Suporte a formatação (negrito, listas, parágrafos)<br>
Conteúdo guardado em HTML na base de dados
</p>

<p><strong>⏱️ Sistema de Timeline (Cronograma)</strong><br><br>
Uma das principais funcionalidades do projeto:<br><br>
Adição de etapas (dia, hora, descrição)<br>
Edição e remoção dinâmica<br>
Organização automática por dias<br>
Armazenamento em HTML na base de dados
</p>

<p><strong>📌 Funcionamento:</strong><br><br>
Dados inseridos no painel<br>
Enviados via formulário (arrays PHP)<br>
Convertidos em HTML no back-end<br>
Guardados na base de dados<br>
Renderizados no front-end
</p>

<p><strong>📸 Carrossel de Imagens</strong><br>
Upload de múltiplas imagens<br>
Organização por drag & drop<br>
Remoção de imagens<br>
Armazenamento em HTML
</p>
