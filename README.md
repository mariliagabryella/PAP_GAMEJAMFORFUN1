🎮 Game Jam For Fun – Website
📌 Descrição do Projeto

O Game Jam For Fun é um website desenvolvido no âmbito do curso Técnico de Gestão e Programação de Sistemas Informáticos (TGPSI), com o objetivo de divulgar e gerir inscrições para um evento real – uma Game Jam destinada a alunos do 9.º ao 12.º ano.

O site permite não só apresentar informações sobre o evento, como também gerir conteúdos de forma dinâmica através de um painel de administração.

🎯 Objetivos
Criar um site funcional e intuitivo
Permitir inscrições online para o evento
Centralizar toda a informação da Game Jam
Desenvolver um sistema de gestão de conteúdos dinâmico
Aplicar conhecimentos de desenvolvimento web
